# 九条組専用計算機 v36

## v36の変更内容

- 豚のワンタップ記録に「結果＋修正履歴をコピー」を追加しました。
- このボタンでコピーした全文を別端末の貼り付け欄へ入れると、集計値と最大500件の個別修正履歴をまとめて引き継げます。
- 引き継ぎ後も、任意の1件の還元額変更・成功／失敗の切り替え・削除・新しい順の取り消しができます。
- 通常の「結果をコピー」は従来どおり読みやすい結果文だけをコピーします。
- 履歴付きコピーには `【九条履歴:v1:...】` という1行を追加します。この行も含めて全文を共有してください。
- 読み取り時にコードの破損や集計値との不一致を検出した場合は、反映せずにコピーし直すよう案内します。
- 反映前の確認画面に、引き継ぐ個別履歴の件数を表示します。
- 「反映前に戻す」を押すと、集計値と個別修正履歴の両方を反映前の状態へ戻します。

### 履歴ごと引き継ぐ方法

1. 渡す側が「📦 結果＋修正履歴をコピー」を押し、全文をSNSへ貼り付ける。
2. 受け取る側が投稿の全文をコピーする。
3. 計算機最下部の貼り付け欄へ入れ、「貼り付け内容を読み取る」を押す。
4. 「🐷個別修正履歴：○件を引き継ぎ」と表示されることを確認し、反映する。

コードがない従来の結果文も、これまでどおり合計値だけ引き継げます。

## v35の変更内容

- 豚のワンタップ記録の下に「過去の記録を選んで修正」を追加しました。
- 任意の1件を選び、還元額の変更・失敗と成功の切り替え・1件削除ができます。
- 変更前に試行回数・成功回数・還元人数の差分を表示し、「変更を確定」で反映します。
- 後から記録した結果はそのまま残り、成功率・コピー文も更新されます。
- 修正後も「記録を1件戻す」を繰り返し使えます。これは最新の結果を取り消す機能で、修正操作自体を戻すボタンではありません。
- 記録は端末内に最大500件保存し、再読み込み後も一覧から修正できます。既存の有効なワンタップ記録も引き継ぎます（古い記録には日時がありません）。
- 対象は豚のワンタップ記録のみ。手入力や還元の＋／－操作、保存集計・貼り付け内容の反映、一括消去をすると個別記録一覧はリセットされます。ルーレット・野球の操作では消えません。
- 貼り付けや保存集計には各回の内訳がないため、その内訳は復元しません。引き継いだ数値を基準に、それ以降のワンタップ記録を修正できます。
- 一覧は折りたたみ式で、新しい順に20件ずつ表示します。

### 使い方

1. 豚の「過去の記録を選んで修正」を開く。
2. 対象の記録の「修正」を押す。
3. 変更後の結果（または1件削除）を選ぶ。
4. 数値の変更内容を確認して確定する。キャンセルなら数値は変わりません。

## v34の変更内容

- 端末に古いJavaScriptが残っていても、貼り付け引き継ぎ枠が最下部に表示されるよう修正しました。

- SNS結果文の読み取り・確認・反映・反映前へ戻す機能は変更していません。

## 主な機能

- ルーレット・豚・野球の試行回数と成功回数から、それぞれの成功率を計算します。
- 合算成功率は、ルーレットと豚の成功回数・試行回数をそのまま合計して算出します。
- 豚の「結果を1回で記録」では、失敗または2000・2500・3000・3500・4000・4500還元の成功を1タップで記録できます。
- 還元成功を押すと、豚の試行回数・成功回数・該当する還元人数を同時に1ずつ増やします。
- 「記録を1件戻す」を押すたびに、ワンタップ記録を新しい順に最大500件まで取り消せます。
- コピー文では、還元人数を `2000🐷2回　2500🐷3回` の形式で豚の成功率の次の行に表示します。0人の項目は表示しません。
- ＋／－操作やワンタップ記録の内容を画面上部へ表示し、30秒以内の同じ操作を合算します。
- 操作メッセージは1〜600秒で自由に表示時間を設定でき、個別の「消去」ボタンでも閉じられます。
- タップ音は8種類から選択でき、音声ファイルを使わず端末内で生成します。
- 最下部の一括消去では、6つの入力数値・還元人数・このアプリ専用キャッシュを消去します。保存履歴・増減幅・効果音・通知時間は残ります。

## ホーム画面への追加

- Androidの対応ブラウザでは、上部の追加ボタンからインストール確認画面を開きます。
- iPhone・iPadはOSの仕様によりWebページ内のボタンだけでは自動追加できないため、「Safariの共有 → ホーム画面に追加」の手順を表示します。
- LINEやXなどのアプリ内ブラウザでは、SafariまたはChromeで開き直してください。
- ホーム画面から起動した場合、追加ボタンは非表示になります。

## GitHub Pagesへの公開方法

ZIPを解凍し、次のファイルを同じ階層のままGitHubリポジトリへアップロードしてください。

- `index.html`
- `app.js`
- `record-history.js`（v35で追加・必須）
- `install.js`
- `service-worker.js`
- `manifest.json`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

PWA・オフライン機能にはHTTPSが必要です。GitHub PagesはHTTPSに対応しています。

更新後も古い表示が残る場合はオンラインでページを再読み込みしてください。一括消去は入力数値と個別記録も消すため、更新目的だけでは実行しないでください。GitHub上で新規の record-history.js を含め全ファイルが更新されているか確認してください。

## 主な安全対策

- 成功回数が試行回数を超えた入力を拒否
- 整数範囲と合算時の桁あふれを検証
- 保存履歴を最大100件に制限し、壊れた保存データを除外
- 状態反映の直前データを一時保持し、ワンタップで取り消し可能
- アプリ専用の保存キーとキャッシュ名を使用
- 一括消去では `success-rate-calc-` で始まるこのアプリのキャッシュだけを削除
- サービスワーカーは同一サイトの無関係な通信をキャッシュしない
