# 九条組専用計算機 v16

## v16の変更内容

- ＋／－操作の集計メッセージを画面上部中央へ固定しました。
- メッセージは、最後に同じ操作をしてから2分間表示します。
- 入力欄と＋／－の方向ごとに、前回の操作から30秒以内に押した回数と実際の増減量を合算します。
- 別の入力欄や反対方向を操作した場合は、先のメッセージを残して下へ順番に追加します。
- 音量調節バーと「テーマ」音を削除しました。
- タップ音を8種類（ポチッ、ポコッ、ピコン、カチッ、コイン、しずく、ビープ、キラッ）へ増やしました。
- 音はWeb Audioで端末内生成するため、音声ファイルは追加していません。
- 合算成功率は「回数を合算」だけに整理しました。
- 最下部の一括消去で、4つの入力数値とこのアプリ専用キャッシュを消去します。履歴・増減幅・効果音設定は残ります。
- タイトル下にiPhone・Android共通の「ホーム画面に追加」ボタンを設置しています。
- 画面拡大を抑止するViewport設定、タップ操作設定、iOSジェスチャー抑止を追加しました。

## ホーム画面への追加

- Androidの対応ブラウザでは、追加ボタンからブラウザのインストール確認画面を開きます。
- iPhone・iPadはOSの仕様により、Webページ内のボタンだけで自動追加できません。追加ボタンを押すと「Safariの共有 → ホーム画面に追加」の手順を表示します。
- LINEやXなどのアプリ内ブラウザでは、SafariまたはChromeで開き直してください。
- ホーム画面から起動した場合、追加ボタンは非表示になります。

## GitHub Pagesへの公開方法

ZIPを解凍し、次のファイルを同じ階層のままGitHubリポジトリへアップロードしてください。

- `index.html`
- `app.js`
- `install.js`
- `service-worker.js`
- `manifest.json`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

PWA・オフライン機能にはHTTPSが必要です。GitHub PagesはHTTPSに対応しています。

更新後も古い表示が残る場合は、ページを再読み込みしてください。必要に応じて最下部の「数値・キャッシュを一括消去」を実行し、もう一度ページを開いてください。

キャッシュ消去後にオフライン利用を再準備するには、オンライン状態でページを一度開き直してください。

## 主な安全対策

- 成功回数が試行回数を超えた入力を拒否
- 整数範囲と合算時の桁あふれを検証
- 履歴を最大100件に制限し、壊れた保存データを除外
- アプリ専用の保存キーとキャッシュ名を使用
- 一括消去では `success-rate-calc-` で始まるこのアプリのキャッシュだけを削除
- サービスワーカーは同一サイトの無関係な通信をキャッシュしない
