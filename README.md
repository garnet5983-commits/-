# 九条組専用計算機 v12

## 公開方法

このフォルダ内のファイルを、同じ階層のままWebサーバーまたはGitHub Pagesへアップロードしてください。

PWA・オフライン機能には `https://`（または開発用の `localhost`）が必要です。`index.html` を端末内で直接開いた場合、計算機能は使えますがサービスワーカーは動作しません。

## 公開に必要なファイル

- `index.html`
- `app.js`
- `service-worker.js`
- `manifest.json`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

`kujo-icon-source.png` は九条アイコンの高解像度編集用データなので、公開時は省略できます。

## 主な修正

- 成功回数が試行回数を超えた場合は計算せず、エラーを表示
- 成功回数を0以上、試行回数を1以上の安全な整数に限定
- 合算時の桁あふれを防止
- 履歴を最大100件に制限し、壊れたデータを安全に除外
- 履歴表示から `innerHTML` を排除し、文字列として安全に表示
- 保存・コピー失敗時に成功表示を出さないよう修正
- 保存キーをアプリ専用名に変更し、旧版データを安全に移行
- 不要だった再計算ボタンを削除
- ラベル、読み上げ、フォーカス表示、タップ領域、画面拡大、iPhoneの安全領域を改善
- サービスワーカーが他アプリのキャッシュを削除しないよう修正
- キャッシュ対象をアプリの静的ファイルだけに限定
- クエリ付きURLからのオフライン起動に対応
- アプリ名を「九条組専用計算機」へ変更
- セリフを除去した九条の正方形ホーム画面アイコンへ変更
- ミュートボタン横に、開閉式の音量調節スライダーを追加
- 最下部に二段階確認付きの数値一括リセットを追加
- リセット確認は8秒で自動的に閉じ、履歴・増減幅・音量設定を保護
- ＋／－ボタンの連打後に、押した回数と実際の増減合計をメッセージ表示
- 操作メッセージを画面上部に約3秒間表示

## 確認済み項目

- JavaScript構文
- Manifest JSON
- HTML内IDと参照ファイルの整合性
- 4種類の計算モード
- 不正入力の拒否
- 履歴の保存・移行・安全な表示
- ステッパーの上下限
- ステッパー連打回数・増減合計の集計
- PWAキャッシュの対象と削除範囲
- オフライン時のフォールバック
